# SmartCart Kenya

**Shop Smart. Live Better.**

SmartCart Kenya is a Kenya-first, AI-assisted multi-vendor e-commerce
marketplace connecting customers with approved sellers.

## Technology

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM and migrations: Prisma
- Local infrastructure: Docker Compose

## Project status

Initial repository and architecture setup.

## Development principles

- Validate all untrusted input on the server.
- Enforce authentication, role permissions, and resource ownership.
- Calculate prices and checkout totals on the server.
- Verify payment outcomes with the payment provider.
- Keep secrets out of source control and frontend bundles.
